Connecting Passionate Volunteers with NGOs

An end-to-end event management ecosystem engineered with Node.js, Express, MySQL, and Bootstrap 5.

Our Core Objective

Non-Governmental Organizations (NGOs) perform vital social work but often struggle to attract, coordinate, and retain passionate volunteers. Similarly, individuals willing to contribute their time lack a centralized, transparent platform to discover upcoming drives.

HopeConnect bridges this gap by enabling real-time event creation by verified NGOs, instant event discovery for volunteers, capacity control to prevent overcrowding, and complete administrator oversight.

Technical Architecture

  • Frontend: HTML5, Responsive Bootstrap 5.3, Custom CSS Variables, Modular ES6 JS.
  • Backend REST API: Node.js with Express.js Framework, MVC Design Pattern.
  • Database: Relational MySQL Database (`mysql2/promise` pool) with prepared SQL queries.
  • Security: bcryptjs password hashing and JWT token role-based authorization.

Platform Role Workflows

Designed for three distinct user roles with full access controls.

Volunteer

  • Register / Login account
  • Browse events with real-time filters
  • Register for events (prevents duplicates & full capacity)
  • Manage registrations on Volunteer Dashboard
  • Cancel registered events anytime

NGO Organization

  • Register NGO account with organization profile
  • Create new events with date, time, location, max slots & image
  • Edit or delete existing events
  • View real-time list of registered volunteer attendees

System Admin

  • Access high-level system analytics & metrics
  • Manage all registered Volunteers and NGOs
  • Monitor and delete inappropriate events
  • Audit all active registrations across the platform
